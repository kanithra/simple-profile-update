# Simple User Information Form

This is a basic HTML + JavaScript project that allows users to enter their:
- Name
- Email
- Phone Number
- Address

When the user clicks the **Submit** button, their input is displayed below using JavaScript DOM manipulation.

##  Technologies Used

- HTML
- JavaScript 

## 🚀 How to Run

1. Clone the repository or download the ZIP.
2. Open `index.html` in your browser.
3. Fill the form and click **Submit**.
4. Your inputs will appear below the form.

## ✨ Output Example

Name: John Doe
Email: john@example.com 
Number: 1234567890
